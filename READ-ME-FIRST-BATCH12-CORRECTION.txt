HOW TO INSTALL
1. Extract this ZIP on your iPad.
2. Upload the .js.txt file to your GitHub repository root, commit to main.
3. Open the uploaded .js.txt, copy the entire content using the Raw copy icon.
4. Open the EXISTING recipe-updates.js in Edit mode.
5. Paste this corrected Batch 12 block AT THE VERY END, after all earlier
   batches, and commit to main. It overwrites the two recipe records by ID
   without removing any previous recipes. Do NOT replace the whole file.
6. Reload your live site. If an older Batch 12 was appended already, this
   corrected block must come AFTER it so the real-photo URLs take precedence.

If you require local JPG files in the ZIP or the exact previously chosen
reference image, these URLs are not equivalent to that request.
