GITHUB UPLOAD — TWO STEPS
1. Unzip and upload ALL FIVE files to the ROOT of
   https://github.com/maikascookbook/maikascookbook.github.io
   using Add file > Upload files, then commit to main.
2. Open ADD-TO-END-of-recipe-updates-BATCH14-FINAL.js.txt and copy ALL its code.
   Open your EXISTING recipe-updates.js, tap Edit, scroll to the very bottom,
   PASTE the new code AFTER Batch 13, and commit.
   DO NOT REPLACE the existing recipe-updates.js or erase earlier batches.
